# Taylormade Podcast for Mac — beta downloads

Record a video podcast on up to four cameras and two mics with one Mac.

**Download and install:** https://www.taylormadecreative.net/podcast-app/

Each release has a signed, notarized `TaylormadePodcast.dmg` for macOS 15 or later (Apple silicon or Intel).
